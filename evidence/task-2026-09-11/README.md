## 2. Modal tap-test preregistration — `docs/specs/mast-modal-tap-test/preregistration.md`

Generated by `experiments/tap_test_prereg.py` from `parameters.csv`, the new `modal-inputs.csv`
(10 rows, all pending), `runs/mast_fea/fea_summary.txt` and the design doc. It freezes the
hypothesis, the prediction sources, the band **form** (model-discrepancy term separate from a
k = 2 measurement-uncertainty term) and the procedural rules; it emits **no numeric band** while
any modal input is pending. Nominal expectations reproduced with the repository's own code:
hand 330.1 Hz, FEA 285.5 Hz. **174.7 Hz is the rejected §3.1 baseline (L = 120 mm, OD 16 mm), not
the test target** — an earlier session note describing a "pass band around 174.7 Hz" was wrong on
that point and is corrected here.
