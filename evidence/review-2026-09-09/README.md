- **P1 acceptance gap:** RR-CAD-08 was marked done even though its required geometry
  workflow existed only as an inert patch. It is now **in_progress** until the
  installed job runs green on the amended PR. The parent reviewer verified current
  workflow permission; the historical token limitation is not a current blocker.
- **P1 admission gap:** filled-in `pending` or empty evidence states generated
  geometry; duplicate rows silently overwrote previous values; NaN/infinity
  passed numeric parsing. The parser now rejects all three classes before build.
  An allowed state label is still not independent authentication of its source.
- **P2 verification gap:** the old lock test checked only Python and CadQuery.
  OCP, NumPy and pytest could drift unnoticed. All five explicit constraints are
  now tested, with the imported OCP version used when Conda omits Python package
  metadata. This is not a platform/build/transitive lock.
- **P2 round-trip gap:** the old round-trip test compared volume only. Synthetic
  changes to imported bounding dimensions or solid count passed. The round-trip
  gate now checks the full existing metric contract, including mass where defined.

Day 1's separation of sourced nominal dimensions, assumptions and unknowns is
useful and should stay. The limited day-2 family is a tooling demonstration, not
fixture CAD. Do not add fit dimensions or a prop swept thickness just to make the
model look more complete. Actual interfaces, metrology and containment remain
