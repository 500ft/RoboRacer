# LiDAR Mast Physical Validation — Execution Plan

1. Release CAD and the critical-to-function drawing.
2. Order the 6061-T6 tube, base/fixture material, fasteners, 0.001 mm indicator
   and base, and any external fabrication service immediately.
3. Fabricate and inspect the mast/fixture; save the traveler and as-built
   dimensions.
4. Regenerate hand and FEA compliance using as-built dimensions.
5. Calibrate the load cell and indicator; measure fixture motion.
6. Execute both axes, five load levels, and at least three load/unload cycles.
7. Calculate the uncertainty budget without changing exclusions or thresholds.
8. Run the committed analyzer and publish VALIDATED, DISCREPANCY, or
   INCONCLUSIVE. Permit one documented root-cause/retest cycle.
9. Update the README and evidence release with the verdict, raw CSV, calibration
   records, plot, media, and exact reproduction command.

The packet deadline does not convert missing or low-quality data into a pass.
